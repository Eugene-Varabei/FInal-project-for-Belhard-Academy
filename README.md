📈 Прогнозирование курса USD/BYN с помощью машинного обучения

Проект посвящён анализу динамики и прогнозированию курса доллара США к белорусскому рублю (USD/BYN) на основе исторических данных и макроэкономических факторов с использованием методов машинного обучения.

Цель проекта — исследовать взаимосвязь валютного курса с экономическими показателями, построить прогнозные модели и сравнить их точность на исторических данных.

🎯 Цели проекта

Провести исследовательский анализ данных (EDA).

Подготовить исторические данные для моделирования.

Исследовать влияние макроэкономических факторов на динамику USD/BYN.

Построить и сравнить несколько моделей прогнозирования.

Оценить качество прогнозов с помощью статистических метрик.

Проанализировать важность признаков для моделей на основе деревьев решений.

📊 Используемые данные

В проекте используются ежемесячные данные о валютных курсах и экономических показателях.

Показатель

Описание

USD_BYN - Курс доллара США к белорусскому рублю — целевая переменная
FED_FUN_EFF_rate - Эффективная ставка по федеральным фондам США
NB_Rate - Ставка Национального банка
DXY - Индекс доллара США
Gold_USD - Цена золота
Brent_Oil - Цена нефти Brent
EUR_USD - Курс евро к доллару США
USD_RUB - Курс доллара США к российскому рублю
BTC_USD - Цена биткоина в долларах США
Date - Дата наблюдения

Исходные данные хранятся в файле DATASET.xlsx.

⚙️ Этапы работы

1. Предварительная обработка данных

Загрузка данных из Excel.

Преобразование дат в формат datetime.

Обработка пропусков методом линейной интерполяции для отдельных экономических показателей.

Формирование лаговых признаков.

Создание признака месяца для учёта сезонности.

Удаление строк, содержащих пропуски после формирования лагов.

Очищенный набор данных сохраняется в Clean_dataset.xlsx.

2. Создание признаков

Для прогнозирования используются значения экономических показателей за предыдущий месяц, а также лаг курса USD/BYN:

курс USD/BYN за предыдущий месяц;

цена биткоина;

цена нефти Brent;

цена золота;

курс EUR/USD;

курс USD/RUB;

индекс DXY;

эффективная ставка федеральных фондов США;

ставка Национального банка;

номер месяца.

Использование лаговых признаков позволяет учитывать предшествующую динамику временного ряда.

3. Исследовательский анализ данных (EDA)

Выполняются:

анализ структуры и типов данных;

проверка пропусков и дубликатов;

визуализация динамики курса USD/BYN;

построение корреляционной матрицы;

анализ распределения целевой переменной.

4. Разделение данных

Данные разделяются с сохранением временного порядка:

Обучающая выборка — исторические наблюдения до тестового периода.

Тестовая выборка — последние 24 месяца.

Такой подход позволяет оценивать качество моделей на более поздних наблюдениях, не перемешивая данные случайным образом.

5. Построение моделей

В проекте сравниваются четыре алгоритма машинного обучения:

Модель

Назначение

Linear Regression

Базовая линейная модель для оценки зависимостей между признаками и курсом

Decision Tree Regressor

Модель, способная учитывать нелинейные зависимости

Random Forest Regressor

Ансамбль деревьев решений для повышения устойчивости прогнозов

LightGBM

Градиентный бустинг на деревьях решений

Дополнительно реализовано прогнозирование линейной регрессией методом Walk-Forward Validation с расширяющимся обучающим окном: модель последовательно переобучается при переходе к следующему месяцу тестового периода.

6. Проверка предпосылок линейной регрессии

Для анализа линейной модели используются статистические тесты:

Тест Рамсея RESET — проверка возможной неправильной спецификации модели.

VIF — оценка мультиколлинеарности признаков.

Тест Бройша — Пагана — проверка гомоскедастичности остатков.

Тест Бройша — Годфри — проверка автокорреляции ошибок.

Статистика Дарбина — Уотсона — дополнительная диагностика автокорреляции.

Тест Жарка — Бера — проверка нормальности остатков.

Результаты используются для анализа ограничений линейной регрессии и интерпретации её прогнозов.

7. Оценка качества моделей

Для сравнения прогнозов рассчитываются три метрики:

Метрика
MAE - Средняя абсолютная ошибка прогноза
RMSE - Корень из средней квадратичной ошибки
MAPE - Средняя абсолютная процентная ошибка

Чем меньше значения этих метрик, тем ближе прогнозы модели к фактическим значениям.

8. Интерпретация результатов

Сравнение фактического курса с прогнозами моделей.

Определение модели с минимальным MAPE на тестовой выборке.

Анализ важности признаков в LightGBM и Random Forest.

Формирование аналитических выводов о результатах моделирования.

⚠️ Ограничения

Качество прогнозирования зависит от полноты и качества исторических данных.

Связи между валютными курсами и макроэкономическими показателями могут меняться со временем.

Статистические зависимости не обязательно означают причинно-следственные связи.

Фактические значения внешних факторов за прогнозируемый месяц могут быть неизвестны в момент реального прогнозирования. Их использование без предварительного прогноза может приводить к утечке будущей информации.

Результаты на тестовом периоде не гарантируют аналогичную точность в будущем.

📌 Итог

Проект объединяет методы анализа временных рядов, статистической диагностики и машинного обучения для исследования и прогнозирования курса USD/BYN.

Сравнение нескольких алгоритмов позволяет оценить, какие подходы лучше описывают исторические данные и показывают более высокую точность на отложенном периоде.

Основной результат проекта — сравнительный анализ моделей прогнозирования валютного курса с использованием временного разделения данных, статистических метрик и визуализации результатов.
